# Session logs

Session logs record agent work; they are not an authority for current behavior.
Use one log only when a multi-step session needs a handoff or audit trail.

Name files YYYY-MM-DD-short-topic.md and include:

- Date, agent, branch, and pull request.
- Goal and changes made.
- Decisions and reasons.
- Open issues and follow-ups.
- Links to durable documentation updated during the session.

Promote every lasting decision, command, or architecture change to its canonical
documentation page. Keep only the session-specific history here. Git history
remains the archive for deleted logs.
